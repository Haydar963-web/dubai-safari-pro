### 🏝️ Dubai Tourism Website Project

This project is a dynamic and responsive web application showcasing a variety of tourist trips within Dubai. It features a clean design, optimized performance, and a user-friendly interface built with **React**, structured for scalability and maintainability.

### ✨ Key Features:

- **Dynamic Tour Display**: Each trip includes details such as duration, cost per person, and places to visit.
- **Dynamic Pagination System**: Displays 6 tour cards per page with a navigation counter at the bottom. New trips are automatically integrated without manual updates.
- **Dedicated Pages**: About, Login, and Register, with seamless routing powered by **React Router**.
- **Interactive Notifications** using **React Toastify**.
- **Responsive Design** using **pure CSS**, without external libraries like Bootstrap or Tailwind.
- **Clean Code Architecture** with well-organized components and folders.
- **Performance Optimization** through minimal and efficient code for a smooth user experience.

### 🛠️ Technologies Used:

- React
- JavaScript
- React Router
- React Toastify
- Puer CSS
- Dynamic Pagination
- Fully Responsive Design
- BootStrap Icon From CDN

### 🏝️ مشروع موقع الرحلات السياحية في دبي

هذا المشروع هو تطبيق ويب تفاعلي يعرض مجموعة من الرحلات السياحية داخل مدينة دبي، مع واجهة مستخدم سلسة وتصميم احترافي يركز على الأداء وتجربة المستخدم. تم تطويره باستخدام مكتبة **React**، ويتميز بتنظيم دقيق للمكونات والملفات، مما يسهل الصيانة والتوسع مستقبلاً.

### ✨ الميزات الرئيسية:

- **عرض ديناميكي للرحلات السياحية**: يشمل تفاصيل مثل مدة الرحلة، التكلفة لكل شخص، والأماكن التي سيتم زيارتها.
- **نظام Pagination ديناميكي**: يتم عرض 6 بطاقات رحلات في كل صفحة، مع إمكانية التنقل بين الصفحات عبر عداد أسفل الصفحة. يتم تحديث المحتوى تلقائيًا عند إضافة رحلات جديدة دون الحاجة لتعديل يدوي.
- **صفحات مخصصة**: "حول"، "تسجيل الدخول"، و"إنشاء حساب"، مع تنقل سلس باستخدام **React Router**.
- **تنبيهات تفاعلية** باستخدام مكتبة **React Toastify**.
- **تصميم سريع الاستجابة** باستخدام **CSS خالص** بدون أي مكتبات خارجية مثل Bootstrap أو Tailwind.
- **تنظيم احترافي للكود والمجلدات** لتسهيل التطوير المستقبلي.
- **تحسين الأداء** عبر تقليل الكود غير الضروري للحصول على تجربة مستخدم سلسة وسريعة.
